Privacy Policy of UV radiation now

The UV radiation now app resolves the current location of the device to resolve the UV index. When the UV index is resolved, a request is sent over the network to a server. The location of the device and other technical details are collected automatically on the server for product development and statistical purposes.

The following information is collected:

  • The latitude and longitude of the device as returned from the GPS receiver.
  • The altitude of the device, if available, as returned from the GPS receiver.
  • The name of the browser, the bowser version, the name of the browser engine and the browser engine version.
  • The name of the operating system and the version of the operating system.
  • The remote IP address of the computer from which the request was made.
  • The remote host name of the computer from which the request was made.
  • The timestamp of the request.

It is not possible to identify the user of the device nor a specific device from the collected information.

The UV radiation now app may display ads. The ads are served using the Google AdMob platform. Please review the Google Privacy Policy to understand what data may be collected by Google for better serving the ads.
